Train a Machine Lab · Grades 6–8

For teachers & grown-ups

Two modes (start screen):

  • Teacher-Led: projected · discussion prompts · class votes · teacher reveals · no individual scores
  • Student-Led: solo · short written steps on every mission · hints · instant feedback and scores
  • Sound is optional, never required: every direction, question, and piece of feedback is written and shown on screen, so the lab runs fully muted — in a quiet classroom, without headphones, or on a device with no audio. The small “Optional: Hear it” buttons in Student-Led mode only read the same written steps aloud for students who prefer to listen as well; nothing is audio-only.
  • Switch modes any time from the tracker.

How it works:

  • The workflow: label → build a dataset → train → test → investigate bias.
  • The Mission 3 test runs on the student's own Mission 2 dataset — the model only knows colors it trained on (plus one generalization case), so better data visibly raises the score.
  • Key words: training data, label, dataset, model, training, prediction, test data, accuracy, bias.

Extend it:

  • Discuss: Where have you seen a system work well for some people and badly for others? What might its training data have looked like?
  • Go further: Teachable Machine (teachablemachine.withgoogle.com) · Day of AI's "How Do Machines Learn?" unit.
  • Challenge: Hit 100% — then make the model fail on purpose, and explain which data choice caused it.
