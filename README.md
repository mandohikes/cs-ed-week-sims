# CS Education Week 2026 — Simulations

Twelve interactive classroom simulations for Mississippi Computer Science Education Week, December 7-11, 2026, built by the MSU Center for Cyber Education.

Open `index.html` (or the GitHub Pages site) and pick a grade band: K-2, Grades 3-5, Grades 6-8, or Grades 9-12. Each band has three different simulations. Every simulation runs in a browser with no accounts and no data collection, has Teacher-Led and Student-Led modes, needs no sound, and includes a Teacher bypass button (corner of the screen) to jump, skip, reveal, or reset.
